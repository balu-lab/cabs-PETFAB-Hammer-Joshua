# Lesson 2: Building the Robotic Arm

Students work in groups to assemble the arm they will use for the rest of the course. They build the links and joints, wire the actuators to the controller, and run a first power-on test to confirm every joint moves. The lesson also covers basic troubleshooting of common assembly mistakes.

**Time:** two class periods (about 60 minutes each)

## Objectives

By the end of this lesson, students will be able to:

- Assemble the arm's mechanical parts (links, joints, mounting hardware) by following a build guide
- Correctly wire the actuators to the controller
- Check that each joint moves correctly with a basic functional test
- Identify and fix common assembly errors (loose connections, reversed wiring, misaligned joints)
